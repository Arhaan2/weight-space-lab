Read the evidence

What does “strict” mean? A prompt passes only when every specified instruction passes the official strict checker. Loose scoring allows the evaluator’s defined response variations. It is not a general measure of answer quality.

What stayed fixed? Both V1 artifacts used Qwen3.5-0.8B, q4f16_1, WebLLM 0.2.86 and the same compiled model library. Thinking was disabled, temperature was zero, and the output ceiling was 1,024 tokens.

Why keep the uncertainty visible? The strict estimate is +0.78 percentage points, but the 95% interval spans −5.47 to +7.03. The data do not establish improvement or equivalence.

Where are the full results? The canonical V1 JSON includes all four compliance metrics, paired outcomes, interruptions and resource accounting. The reproduction record carries immutable model, runtime and evaluator pins.

Why no fresh V2 test? The final-data exposure audit could not establish untouched official prompts. The existing V1 test is not reused as fresh confirmation.

Whose work makes this possible? Qwen; WebLLM and MLC; Google Research IFEval and Ai2 RLVR-IFeval; Browser LLM Bench by Gufran Mirza and Arhaan Aggarwal; and Sparks of Weight-Space Programming by Rikiya Takehi, Jayden Teoh, Alex Zhang and Omar Khattab.
